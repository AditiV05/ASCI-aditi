## 📌 About

ASCI 2025 is an international academic conference. This website is its central hub — covering event overview, schedule, speakers, committees, and registration. Built solo from UI design to live deployment, the site has been serving real users since launch.

---

## ✨ Highlights

- **Multi-page architecture** with React Router — dedicated routes for Authors, Speakers, Committees, Tech Committee, Workshop, and Contact
- **Scroll-triggered animations** powered by AOS (Animate On Scroll) for smooth, professional reveals
- **Speaker carousel** built with Swiper for interactive speaker showcase
- **Sticky scroll-aware header** that changes background and shadow on scroll
- **Custom mobile menu** with slide-in panel, overlay, and hamburger-to-cross icon transition
- **Dropdown navigation** with hover states and accessible mobile fallback
- **Auto-revealing scroll-to-top button** for fast navigation on long pages
- **Three-tier responsive design** — optimized breakpoints at 1024px, 768px, and 480px
- **Custom CSS architecture** — hand-built styling, no UI framework
- **Live in production** — actively used by conference participants
